## Problemas

- **Problema 1 (Figuras):** clase abstracta `Figura` con `Rectangulo`, `Cuadrado` y `Triangulo`. Se guardan en un arreglo `Figura[]` y se recorre mostrando el área y el perímetro de cada una (polimorfismo). Aplicación de consola.
- **Problema 2 (JSON):** serializa un objeto persona a formato JSON usando Newtonsoft.Json y lo muestra en consola.
- **Problema 3 (Login con BCrypt):** aplicación Windows Forms con registro e inicio de sesión. Las contraseñas se guardan como hash BCrypt en MySQL y cada intento de login queda registrado en la base de datos.
